

This repository contains the scripts, methodology, preprocessing workflow, and study-area information used in my **water level prediction study** using machine-learning approaches.

## Repository Structure

### `Methodology/`

Contains the **overall research workflow and methodology flowchart**, showing the steps followed from data preparation and preprocessing to machine-learning modeling and evaluation.

### `Preprocessing/`

Contains the data preprocessing scripts used to handle missing water-level observations and prepare the datasets for modeling.

### `Original_Data_Scripts/`

Contains the **machine-learning model scripts** developed for the study. These include models such as:

* Multiple Linear Regression (MLR)
* Random Forest (RF)
* XGBoost (XGB)
* LightGBM (LGBM)
* CatBoost

These scripts are used for model development, prediction, and performance evaluation.

### `Study Area/`

Contains the **study-area map** showing the geographical location and relevant monitoring stations considered in the water-level study.

## Purpose

The repository is organized to document the computational workflow of the study, from **data preprocessing to machine-learning-based water-level prediction**, while providing the supporting methodology and geographical context.
